# leap_year_py-vibe-code
python leap year task
## Промпт

Сгенерируй короткую Python-функцию, которая проверяет, является ли введенный год високосным.

## Ручной аудит

Проверено правило: год високосный, если делится на 4, но не делится на 100, кроме годов, которые делятся на 400.

## Проверочные примеры

- 2000 — високосный, потому что делится на 400.
- 1900 — не високосный, потому что делится на 100, но не делится на 400.
- 2024 — високосный, потому что делится на 4 и не делится на 100.
- 2023 — не високосный, потому что не делится на 4.

## Вывод

Функция корректно учитывает третье условие правила: годы, делящиеся на 400, являются високосными.
