# Проверка високосного года

Консольное приложение на Python для проверки, является ли введенный год високосным.

## Основные возможности

- проверка одного года;
- проверка нескольких годов через запятую;
- поиск следующих 5 високосных годов;
- демонстрационные проверки;
- вывод меню и сообщений на русском языке;
- обработка некорректного ввода.
