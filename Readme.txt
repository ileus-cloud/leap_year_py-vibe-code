Проверка високосного года

Описание проекта

Это небольшое консольное приложение на Python, которое проверяет, является ли введенный год високосным.

Правило определения високосного года:
год является високосным, если он делится на 4, но не делится на 100,
кроме годов, которые делятся на 400.

Реализованные доработки:

1. Добавлено консольное меню на русском языке.
2. Добавлена проверка корректности пользовательского ввода.
3. Добавлена проверка одного года.
4. Добавлена проверка нескольких годов, введенных через запятую.
5. Добавлен поиск следующих 5 високосных годов после введенного года.
6. Добавлены демонстрационные проверки для важных граничных случаев.

Дополнительные доработки:

- Приложение не падает, если пользователь вводит текст вместо числа.
- Приложение объясняет, почему год является или не является високосным.
- Можно проверить сразу несколько годов за один запуск.
- Можно узнать следующие 5 високосных годов после выбранного года.
- В приложение добавлены встроенные демонстрационные проверки.
- Все команды меню и сообщения в консоли выводятся на русском языке.

Контрольные проверки:

Функция проверки високосного года была проверена по ключевому правилу:

year % 4 == 0 and (year % 100 != 0 or year % 400 == 0)

Проверенные примеры:

2000 - високосный год, потому что он делится на 400.
1900 - не високосный год, потому что он делится на 100, но не делится на 400.
2024 - високосный год, потому что он делится на 4 и не делится на 100.
2023 - не високосный год, потому что он не делится на 4.

Проверка после запуска

После запуска появится меню:

1. Проверить один год
2. Проверить несколько годов
3. Показать следующие 5 високосных годов
4. Запустить демонстрационные проверки
5. Выход

Рекомендуемые проверки:

- 2000 должен быть високосным годом;
- 1900 не должен быть високосным годом;
- 2024 должен быть високосным годом;
- 2023 не должен быть високосным годом;
- ввод текста, например abc, должен показать ошибку ввода;

После запуска выберите нужный пункт в консольном меню:

1. Проверить один год
2. Проверить несколько годов
3. Показать следующие 5 високосных годов
4. Запустить демонстрационные проверки
5. Выход

Примеры проверок

Для проверки одного года выберите пункт 1 и введите, например:
